Setup required: you must add a GitHub token before you can save anything. Follow the steps below.

GitHub token (required)

The token lets this page save your encrypted notes to your repo. It's stored encrypted inside the vault, so you only do this once.

  1. Log in to GitHub as elipinals12, then open github.com/settings/personal-access-tokens/new.
  2. Token name: type admin notepad.
  3. Expiration: pick the longest option. When it expires, repeat these steps.
  4. Repository access: choose Only select repositories, then pick elipinals12.github.io.
  5. Permissions: click Add permissions (or expand Repository permissions), find Contents, and set it to Read and write. Leave everything else alone.
  6. Click Generate token, then Generate token again to confirm.
  7. Copy the token (starts with github_pat_). GitHub shows it only once.
  8. Paste it below and click verify & save.
